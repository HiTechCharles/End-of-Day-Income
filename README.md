# End of Day Drawer

Simple Windows Forms application for calculating and recording end-of-day cash drawer totals and related deposits. This solution contains a small .NET Framework (4.8.1) desktop app intended for local use in small business workflows.

## Features
- Enter cash/check/credit totals
- Calculate drawer over/short
- Save or export end-of-day summary (project-specific behavior)

## Prerequisites
- Microsoft Visual Studio (recommended): Visual Studio Community 2026 or compatible
- .NET Framework 4.8.1

## Build & Run
1. Open `End of Day Drawer.sln` in Visual Studio.
2. Restore NuGet packages if prompted.
3. Build the solution (Build -> Build Solution).
4. Run (Debug -> Start Debugging) or start without debugging.

## Project Structure
- End of Day Drawer.sln - Visual Studio solution
- Properties/, bin/, obj/ - build artifacts and configuration
- Form1.cs, Form1.Designer.cs - main Windows Forms UI and logic
